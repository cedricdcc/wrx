## Overview

`wrx` is a zero-dependency Bun/TypeScript module designed for robust web resource extraction from any URI. It retrieves RDF metadata using a cascading strategy, where multiple discovery strategies are tried in priority order, falling back dynamically until RDF metadata is successfully extracted.

## Data Flow

The cascading extraction strategy follows this flow:
1. **Content Negotiation (S1):** Attempts a `fetch` using an `Accept` header specifically listing RDF MIME types.
2. **HTTP Link Headers (S2 & S3):** Parses the `Link` header of the response to locate `rel=describedby`, `rel=profile`, and `rel=linkset` URLs, then resolves them.
3. **HTML Hints (S4, S5, & S6):** If the response is HTML, parses it using `DOMParser` for `<link rel="describedby">`, `<link rel="linkset">`, and embedded `<script>` tags carrying RDF.
4. **Sitemap Signposting (S7):** If all else fails, checks `robots.txt` for a sitemap, parses `sitemap.xml`, and searches for FAIR signposting inside `<url>` entries matching the URI.
5. **Output:** Returns an `ExtractedRDF` object containing the raw RDF string, format, source strategy, and the final URL. Returns `null` if all fail.
